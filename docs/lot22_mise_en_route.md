# Lot 22 - Mise en route (sans rien installer)

Période d'import N-1 + N (décision 0016). Une seule étape : aucune migration, aucun secret, la fonction serveur ne
change pas.

## 1. GitHub : fichiers du lot
Déposer les fichiers de l'archive (glisser-déposer, en respectant les dossiers). Vérifier : **Actions**, « Tests et
publication » avec deux coches vertes.

## 2. Essai
1. Recharger le site sans le cache (Ctrl+F5), choisir « Dossier Pennylane de test ».
2. Import comptable : le cadre « Période importée » remplace les dates. Cliquer **Synchroniser**.
3. Après la synchronisation, le cadre indique les exercices N-1 et N retenus ; le cadre Options indique le nombre
   d'écritures anticipées s'il y en a. L'historique affiche « N-1 + N » dans la colonne Période.
4. La première synchronisation après ce lot peut être une relecture complète (période plus large) : c'est normal.
